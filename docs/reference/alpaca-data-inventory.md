# Alpaca-py stock data inventory

This is a static reference captured from the public interfaces available in
`alpaca-py==0.44.0`. Review it against the SDK documentation when upgrading
`alpaca-py`.

This document supports dataset selection and schema design. It is reference
material rather than a claim that every listed dataset has been implemented.

## What reference datasets mean

Reference datasets describe the market entities and schedule used to interpret event data. They change much less frequently than quotes or trades.

Examples in this inventory are:

- **Stock asset metadata:** symbol, exchange, active/tradable status, and other security attributes.
- **Market calendar:** which dates are trading days and their scheduled open and close times.
- **Market clock:** whether the market is open now and the next scheduled open and close.

Reference data normally becomes dimension tables such as `dim_assets` and `dim_market_calendar`. Quotes, trades, and bars are event or fact datasets.

## Scope note

This inventory covers stock-related public entry points exposed by the installed Alpaca Python SDK. It intentionally excludes crypto, options, brokerage-account operations, order submission, and raw REST endpoints without an SDK wrapper.
